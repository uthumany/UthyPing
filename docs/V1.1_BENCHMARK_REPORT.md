# UthyPing Version 1.1 Performance and Stability Report

This report summarizes the performance metrics, memory stability, and functional validation of the UthyPing GNOME Shell extension after implementing Version 1.1 features (custom panel indicator, icon themes, and refresh intervals).

## 1. Executive Summary

UthyPing Version 1.1 maintains a low performance footprint while adding significant panel customization. Short-term and long-term (5-minute) benchmarks in a nested GNOME Shell 46 environment show no memory leaks and negligible CPU overhead for custom SVG icon rendering and fast panel redrawing.

## 2. Performance Metrics

### Short-Term Impact (10-second capture)
Measured in a nested Wayland Shell session with a custom local SVG and combined download/upload readings at a 250 ms refresh interval.

| Metric | Baseline (Panel Hidden) | Custom SVG Panel Enabled | Delta |
|---|---|---|---|
| **CPU Usage** | 228.499% | 228.036% | −0.463% |
| **RSS Memory (Avg)** | 251.428 MiB | 253.132 MiB | +1.704 MiB |
| **RSS Memory (Max)** | 252.348 MiB | 254.426 MiB | +2.078 MiB |

### Stability Profile (5-minute stress test)
Fastest supported redraw (250 ms) with a cached custom SVG icon.

| Metric | Value |
|---|---|
| **Duration** | 298.05 seconds |
| **Samples** | 150 |
| **Starting RSS** | 252.30 MiB |
| **Ending RSS** | 228.61 MiB |
| **Total Growth** | **−23.69 MiB** |
| **Growth Rate** | **−4.77 MiB/min** |
| **Avg CPU** | 230.335% |

**Analysis:** The negative memory growth provides no evidence of a memory leak in this five-minute run. The resident set size decreased over the profile, consistent with GNOME Shell reclaiming memory. This supports the conclusion that the icon cache and stable actor updates are not causing unbounded object accumulation. A longer run on the target desktop would still be appropriate for release-specific certification.

## 3. Custom SVG Icon Loading

The implementation uses a cached `Gio.FileIcon` mechanism. 

- **Optimization:** SVG files are read and converted to icon objects only once when the path changes.
- **Throttling:** Panel labels are updated in-place on a configurable interval (250–5000 ms), independent of the network monitor's sampling cadence.
- **Safety:** Remote URIs and non-SVG files are rejected. Invalid paths safely fall back to the selected built-in theme (Glass, Network, or Symbolic).

## 4. Functional Validation

All automated and runtime checks passed:

- **Unit Tests:** 20 passing tests covering rate formatting, baseline logic, session statistics, settings validation, and custom SVG path normalization.
- **Schema Validation:** 23 GSettings keys verified with strict compilation and default-value checks.
- **Runtime Integrity:** Successfully reached `ACTIVE` state in multiple nested GNOME Shell 46 sessions.
- **Error Logs:** Zero `JS ERROR`, `St-WARNING`, `TypeError`, or `ReferenceError` reported during active panel customization.

## 5. Conclusion

UthyPing Version 1.1 passed the available automated and nested-shell validation. The custom icon theme loading is optimized for stability and low resource usage, and the extension remained stable under high-frequency panel updates and custom artwork overrides. Target-desktop certification should still include a longer profile on the intended GNOME distribution and hardware.
